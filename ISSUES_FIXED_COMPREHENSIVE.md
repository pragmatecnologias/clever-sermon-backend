### ⚠️ 2. Citations Not Using Bible API
**Status**: NEEDS IMPLEMENTATION

**Problem**: Citations are only generated by LLM, not fetching actual Bible verses from API.Bible.

**Current Implementation**:
- `generateCitations()` only calls LLM
- No integration with Scripture API
- Missing verse text validation

**Required Fix**:
```typescript
// In workspaces.service.ts - generateCitations method
async generateCitations(workspaceId: string, userId: string) {
  // 1. Generate citation ideas with LLM
  const llmResponse = await this.llmService.generateCompletion(prompt, userId);
  const citations = this.parseJsonSafe(llmResponse);
  
  // 2. For each citation with verse references, fetch actual text from API.Bible
  for (const citation of citations) {
    if (citation.verseReferences?.length > 0) {
      const verseTexts = await Promise.all(
        citation.verseReferences.map(ref => 
          this.scriptureService.getPassage(ref, workspace.language === 'es' ? 'RVR60' : 'KJV')
        )
      );
      citation.verseText = verseTexts.map(v => v.verses[0]?.text).join(' ');
      citation.isVerified = true;
    }
  }
  
  return citations;
}
```
